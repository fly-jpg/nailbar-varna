# Промт для сайта визитки Nailbar Varna

Сделай одностраничный сайт визитку для бьюти салона **Nail bar Varna** (Варна, Болгария).

## Факты о салоне
- Instagram: https://www.instagram.com/nailbar_varna/ (запись через Direct)
- Адрес: ул. „Поп Харитон" 8, 9000 Варна (Христо Ботев / Одесос)
- Телефон: +359 88 880 4197
- Часы: каждый день 10:00 до 20:00
- Слоган из профиля: «Твоята beauty-точка наблизо»
- Команда: Анна (владелица, главный эксперт), Аня и Диана (маникюр), София (брови и ресницы, 6+ лет опыта, 600+ образов)
- Есть индивидуальный базовый курс маникюра: 4 дня, сертификат, месяц поддержки

## Услуги (все 5 обязательно)
1. Маникюр: гель-лак, укрепление гелем, комбинированный, френч (нюд и яркий), наращивание
2. Педикюр: аппаратный и комбинированный, покрытие гель-лаком
3. Тростниковый загар (эко тен): ровный оттенок без солнца
4. Ресницы: ламинирование, наращивание
5. Брови: коррекция, окрашивание, ламинирование

## Дизайн
- Палитра: розовые оттенки. Основной малиново-розовый как в логотипе `#E0528A`, светлый пудровый фон `#FFF4F8`, глубокий сливовый для текста `#2B0F1E`, мягкий лиловый акцент.
- Максимально современно: крупная типографика (Unbounded для заголовков, Manrope для текста, обе с кириллицей), мягкие плавающие градиентные пятна, стеклянные карточки (glassmorphism, backdrop-filter blur), скругления 24px+, бегущая строка с услугами.
- Плавное появление блоков при скролле (IntersectionObserver), учитывать `prefers-reduced-motion`.
- Адаптив mobile first: на телефоне одна колонка, липкая кнопка «Записаться» снизу.

## Разделы
1. Шапка: логотип, меню, переключатель языка RU / UA / BG
2. Главный экран: большой заголовок, слоган, кнопки «Записаться» и «Услуги», рейтинг и часы
3. Услуги: 5 стеклянных карточек с иконкой, описанием и списком процедур
4. Галерея работ: сетка плиток в стиле салона со ссылкой на Instagram
5. Почему мы: опытные мастера, стерильность, уют, говорим на 4 языках, курс для новичков; блок с командой
6. Контакты: адрес, часы, телефон, карта Google Maps (iframe), кнопки записи: Instagram Direct, звонок, Viber, WhatsApp

## Языки
Русский, украинский, болгарский. Все тексты в одном словаре в JS, переключение без перезагрузки, выбор сохраняется в localStorage, по умолчанию язык браузера (иначе болгарский). Менять `<html lang>`.

## Техника
Чистый статический сайт: `index.html`, `styles.css`, `app.js`, без сборки и бэкенда. Публикация на GitHub Pages из ветки `main`.

## Тон
Дружелюбно, тепло, на «ты» / «вы» по смыслу, немного эмодзи как в Instagram салона, без канцелярита.
