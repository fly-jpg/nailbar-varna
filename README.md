# Nail bar Varna

Сайт визитка салона Nail bar в Варне. Статический: `index.html`, `styles.css`, `app.js`.

- Языки: RU / UA / BG (все тексты в `app.js`, объект `I18N`)
- Контакты, адрес и часы: `index.html`, блок `#contacts`, и ключи `contacts.*` в `app.js`
- Промт, по которому сделан сайт: `PROMPT.md`

Локально: `python3 -m http.server` и открыть http://localhost:8000

## Заявки «Напишите нам»

Форма в поп-апе (имя, телефон, услуга, комментарий) отправляет заявку в Google таблицу
«Nail bar Varna: заявки с сайта». Скачать как Excel: Файл → Скачать → Microsoft Excel (.xlsx).

Подключение (один раз):
1. Открыть таблицу → Расширения → Apps Script.
2. Заменить код на содержимое `apps-script/Code.gs`, сохранить.
3. Развернуть → Новое развертывание → тип «Веб-приложение», Запуск от: «Я», Доступ: «Все» → Развернуть, разрешить доступ.
4. Скопировать URL веб-приложения (`https://script.google.com/macros/s/.../exec`) в `FORM_ENDPOINT` в `app.js`.
